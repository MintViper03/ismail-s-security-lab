- A single route `/` renders `<Portfolio />`. `__root.tsx` provides the head meta, Google Fonts, the 404 and the error boundary. `server.ts` wraps SSR errors, and `start.ts` adds error and CSRF middleware.

- Deployment: **the repo has no deploy config** (no wrangler/nitro/vercel/netlify files, no CI). `dist/` is a local build output and is gitignored.

## Plan

1. **Wire content, no visual change.** Import `resume.ts` and `site.ts` into `Portfolio.tsx`, `ProfilePhoto.tsx` and `__root.tsx`. Delete the inline `skills`, `timeline`, `sevColor`, the `IncidentCase` log and the hard-coded strings. Render the full bullets, with `<strong>` for `emphasis`. Keep all existing components, animations and anchors.
2. **Fix the resume download.** Use `<a href={resumeDownload.href} download={resumeDownload.fileName}>` in the hero and contact sections.
3. **Contact and meta.** Add TryHackMe (and the phone number if approved), fix the LinkedIn slug, and derive the head meta from `identity` and `summary`.
4. **Credentials section.** Show the certifications with their `status`. The CEH/OSCP entry always shows "in preparation."
5. **Redesign (separate step, after sign-off).** Add the case-study layout for b01–b08 and the new about/education block. Redesign stays out of scope until you ask for it.
6. **Guardrail (optional).** Add a small check script, run in CI or pre-commit, that fails if `resume.ts` drifts from the PDF text, reusing this step's verification logic (needs `pdftotext`).
7. **Verify each step.** Run `tsc --noEmit` and `npm run build`, then check at mobile and desktop widths with reduced motion on and off. Lint stays red until a separate CRLF/prettier clean-up, which should be its own commit so it does not bury content diffs.

## Step 7 status (2026-09-28): exploration layer done

- **Explore portfolio panel** (`ExplorePanel.tsx`): a floating, dismissible pill ("Explore portfolio · n/4") that expands into a non-modal panel with four optional actions. Each action is ordinary section navigation; "Open both projects" also opens both Project details. Escape or the chevron collapses the panel, returning focus to the pill. Hide moves focus to the Commands button, and the panel is restored from the footer or the palette (focus goes to the pill).
- **Progress** (`lib/exploration.ts`): labelled "Portfolio exploration" with the note "…not a measure of skills". It is a 4-segment `role="progressbar"`, and each step shows Done / Not yet in text. A step completes only on real interaction: opening Show full experience, a stage or the role timeline, or 5 s on Experience; opening each project's details; choosing a skill category, disclosure or Show all; 2 s on Certifications. Reading mode, where there is nothing to click, uses dwell for projects and skills. Completion feedback is a polite live-region announcement, a brief tint on the row and one quiet line at 4/4. Progress restored on load is not announced. Reset keeps focus (`aria-disabled`, not `disabled`). There is no XP, score, leaderboard or celebration, and nothing is gated.
- **Storage** (`lib/ui-storage.ts`): only UI preferences (display mode, exploration progress, panel hidden). It falls back to memory when `localStorage` is blocked. There are no accounts, analytics or backend: the only network requests are the site's own assets and the existing Google Fonts.
- **Command palette** (`CommandPalette.tsx`): the existing Radix dialog + cmdk, with a visually hidden title and description. It opens with Ctrl/⌘+K, "/" or the header "Commands" button, and the shortcuts never fire while typing in a field. Actions: go to any of the 7 sections (focus moves to the section heading), switch Reading/Interactive, open or download the resume PDF, email, call, view contact, show the explore panel, reset progress. Escape restores focus to the element that opened it (captured before Radix moves focus, because the modal dialog would otherwise send it to a missing trigger). A word-substring filter replaces cmdk's fuzzy default, which ran "Technical Skills" for the query "call".
- **Reading mode:** a global CSS rule sets `animation: none; transition: none`, on top of the existing gating of Lenis, reveals, scramble, magnetic buttons and the 3D scene. It shows every detail, and all navigation, contact actions and the palette keep working.
